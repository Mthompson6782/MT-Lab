## News & Headlines

- **Freshness rule:** When the user asks for headlines, world news, or "what's going on," always pull the most recent stories from the **last 24 hours**. Never recycle older items or rely on stale memory of past briefings.
- Prefer live web search over cached knowledge for current events.
- Keep headlines tight and current — prioritize overnight and same-day developments.
- If a story was already covered in a previous session, only re-mention it if there's a meaningful new development.
