## 🚀 HOW TO STREAM LOCALLY OR ON GITHUB PAGES

### 1. Launch the Live Web App
Open [`index.html`](index.html) directly in any modern web browser or visit:
**👉 [https://mthompson6782.github.io/MT-Lab/](https://mthompson6782.github.io/MT-Lab/)**

### 2. Run Local Development Server
```bash
# Python 3
python -m http.server 8080

# Then open http://localhost:8080 in your browser
```

### 3. Deploy to GitHub Pages (1-Click)
1. Go to your repository on GitHub: **Settings > Pages**
2. Under **Build and deployment > Source**, choose **Deploy from a branch**
3. Select branch: `main` and folder: `/ (root)`
4. Click **Save** — Your Netflix app goes live at `https://mthompson6782.github.io/MT-Lab/`!
